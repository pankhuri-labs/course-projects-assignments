## Skills shown
- **Machine learning:** linear and logistic regression, regularisation (Ridge/Lasso), tree ensembles (Random Forest, XGBoost), PCA, handling class imbalance (SMOTE)
- **Deep learning:** CNNs for image classification, Conv3D and CNN + RNN (GRU/LSTM) for video
- **NLP and recommender systems:** text cleaning, TF-IDF, sentiment classification, user-based and item-based collaborative filtering
- **Engineering:** custom data generators, model serving with Flask and Gunicorn, cloud deployment
- **Tools:** Python, pandas, NumPy, scikit-learn, statsmodels, TensorFlow/Keras, NLTK, spaCy, Matplotlib, Seaborn
