# Course Projects: Machine Learning, AI and Cybersecurity

Hands-on projects and assignments by **Pankhuri Mishra** from two professional programmes, in machine learning and AI and in cybersecurity and AI, plus self-directed security labs. Each project folder has a short README covering the problem, approach, tools and outcome, alongside the original notebooks, code or reports.

| Programme | Institute | Year | Projects |

| [Executive PG Programme in Machine Learning & AI](iiitb-ml-ai-2022/) | IIIT Bangalore | 2022 | 7 |
| [Professional Certificate Programme in Cybersecurity and AI](iitm-cybersecurity-ai-2026/) | IIT Madras | 2025–26 | 7 |

## Skills shown
- **Cybersecurity:** DAST and finding triage, access control (RBAC, ACLs, SELinux), audit logging, Splunk log analysis, network traffic analysis, MITM and DNS spoofing (lab), digital forensics, NIST CSF and MITRE ATT&CK, AI in the SOC and its governance
- **Machine learning:** linear and logistic regression, regularisation (Ridge/Lasso), tree ensembles (Random Forest, XGBoost), PCA, handling class imbalance (SMOTE)
- **Deep learning:** CNNs for image classification, Conv3D and CNN + RNN (GRU/LSTM) for video
- **NLP and recommender systems:** text cleaning, TF-IDF, sentiment classification, user-based and item-based collaborative filtering
- **Engineering:** custom data generators, model serving with Flask and Gunicorn, cloud deployment
- **Tools:** OWASP ZAP, Docker, Splunk, Wireshark, Ettercap, FTK Imager, Autopsy, auditd, PowerShell, Kali Linux, Python, pandas, NumPy, scikit-learn, statsmodels, TensorFlow/Keras, NLTK, spaCy, Matplotlib, Seaborn
