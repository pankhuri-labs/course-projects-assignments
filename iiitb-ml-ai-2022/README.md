# Executive PG Programme in Machine Learning & AI, IIIT Bangalore (2022)

Hands-on projects from the 2021–22 programme run by IIIT Bangalore with upGrad. They cover the full ML lifecycle: EDA, statistical modelling, classical ML, deep learning (CNN/RNN), NLP and deploying a model as a web app.

| # | Project | Domain | Techniques | Headline result |
|---|---|---|---|---|
| 01 | [Lending Club credit risk EDA](01-lending-club-credit-risk-eda/) | Lending / FinTech | EDA, segmented and bivariate analysis | Identified the main default-risk drivers |
| 02 | [Bike-sharing demand](02-bike-sharing-demand-regression/) | Mobility | Multiple linear regression, RFE, VIF | Test R² ≈ 0.82 |
| 03 | [House price prediction](03-surprise-housing-price-regularization/) | Real estate | Ridge, Lasso, GridSearchCV | Test R² ≈ 0.78 |
| 04 | [Telecom churn](04-telecom-churn-prediction/) | Telecom | SMOTE, PCA, Logistic Regression, Random Forest | F1 0.92 |
| 05 | [Melanoma detection](05-melanoma-detection-cnn/) | Healthcare | CNN, augmentation, class rebalancing | Validation accuracy from 52% to 79% |
| 06 | [Gesture recognition](06-gesture-recognition-cnn-rnn/) | Consumer electronics | Conv3D, CNN + GRU/LSTM, custom generator | Validation accuracy 87.5% |
| 07 | [Sentiment-based recommender (capstone)](07-sentiment-product-recommendation/) | E-commerce | NLP, TF-IDF, collaborative filtering, Flask | Deployed end-to-end app |
